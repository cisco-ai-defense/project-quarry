# Rule pack proposal

**Status: Draft for maintainer review**

The rule pack overview in `rules/README.md` describes core and community
ownership, directory structure, validation, and support. The pack contract in
`rules/rule-packs/README.md` covers identity, metadata, versioning, and
deprecation.

The contribution guidelines in `rules/rules-contribution-guidelines.md` cover
naming, redundancy checks, required artifacts, and review.

Rule relationship metadata, including `similar`, `derived`, and `obsolete`,
remains a proposal for later review.
