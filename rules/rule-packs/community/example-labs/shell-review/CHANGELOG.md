## 0.1.0 — Unreleased

- Add a synthetic community-pack example for a download-to-shell command submitted through a named shell tool.
- `example-labs` and its maintainer handle are illustrative, not a real external publisher or ownership claim.
- Coverage is limited to the `command` argument on `execute_shell`, `run_shell`, and `shell`. A match records submitted text; it does not establish successful execution or lack of approval.
- Quoted demonstrations inside a shell command may also match; this example does not implement a shell parser.
